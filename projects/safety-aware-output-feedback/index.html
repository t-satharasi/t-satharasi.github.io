PX4 quadrotor simulation in Gazebo with acceleration-level control

Safety-critical control · Simulation

A simulation demonstration of safety-aware output-feedback control on a PX4 quadrotor in Gazebo, using acceleration-level commands.

Overview

This project investigates safety-aware output-feedback control in a simulated quadrotor environment. The implementation uses a PX4 flight stack with a Gazebo simulator and an acceleration-level control interface.
